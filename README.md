# Eyes of Heaven PC port: downloads and bug reports

Downloads and bug reports for an unofficial, free fan port of **JoJo's Bizarre Adventure: Eyes of Heaven** (PS4) to Windows.

> **No game files are included, and none ever will be.** You need your own dump of your own copy: the European release **CUSA04909, version 01.00**.
> Not affiliated with Bandai Namco, CyberConnect2, Sony or Shueisha. Not sold, no donations.

## Get it
Download the latest zip from [Releases](../../releases), extract the whole folder, and open `Eyes of Heaven.exe`. The included `README.txt` explains the rest.

## Report a problem
In the launcher, click **Report a problem**. It saves a zip on your Desktop. Then [open a bug report](../../issues/new/choose) and attach that zip.

## Source code
The port is free software under the GNU GPL v2 or later. Each release has its source code attached.
